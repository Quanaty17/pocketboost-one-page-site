Questions people ask

What is a promo code?

It’s a short code you type in at checkout to get money off, free shipping or another perk. Some stores call it a coupon, voucher or discount code. They all work the same way.

How do I use a code on Pocketboost?

Press “Copy” next to any code, then paste it into the promo box at the store’s checkout. If the card says “Get deal”, no code is needed. Just follow the link.

Do codes always work?

Not always. Stores change or end offers without warning, and some codes only work on certain items or for first-time customers. Check the final price at checkout before you pay.

Do the codes work in my country?

Many do, but some offers are limited to certain countries or regions. The store’s checkout will tell you if a code isn’t valid for you.
