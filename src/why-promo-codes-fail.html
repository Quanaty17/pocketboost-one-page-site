Why promo codes fail (and how to fix it)

There's nothing more annoying than getting all the way to checkout, pasting a code, and seeing "this code is invalid". In my experience it's almost never random. There's usually a simple reason, and often you can fix it in a minute.

The code has expired

Stores end offers without warning, and a code that worked last week can be dead today. If the code is old, look for a newer one instead of trying it over and over.

You don't meet the conditions

Many codes need a minimum spend, only apply to certain categories, or exclude items that are already on sale. Read the small print next to the code. If you're a few rand short of the minimum, adding a cheap item might unlock the discount and still save you money overall.

It's for new customers only

A lot of the biggest discounts are meant for first-time shoppers. If you already have an account with the store, the code may be rejected even though it's valid.

It doesn't work in your country

Some offers are limited to certain countries. The checkout will usually tell you if a code isn't valid where you live. This is a big one for shoppers outside the US and Europe.

You can't stack it with another offer

Most stores only let you use one code per order. If you've already got an automatic discount, a second code may cancel the first.

A small typo

Codes are often case-sensitive, and an extra space can break them. Copy and paste instead of typing, and delete any space at the end.

If you've tried all of this and it still doesn't work, the offer has probably ended. You can also take a look at our guide on how to use a promo code to double check your steps.
